# sm_network packages

| Package | Description |
| ------- | ----------- |
| [`sm_network`](sm_network/) | Dart networking library built on Dio. |
| [`sm_network_proxy`](sm_network_proxy/) | Optional Flutter plugin for Android and iOS system proxy support. |

The packages are kept as independent publishable units, following the layout
used by Flutter's federated plugin families.

## Releases

- `vX.Y.Z` publishes `sm_network/`.
- `proxy-vX.Y.Z` publishes `sm_network_proxy/`.
