# sm_network packages

| Package | 说明 |
| ------- | ---- |
| [`sm_network`](sm_network/) | 基于 Dio 的 Dart 网络请求库。 |
| [`sm_network_proxy`](sm_network_proxy/) | 提供 Android 和 iOS 系统代理能力的可选 Flutter plugin。 |

两个 package 作为独立发布单元并列维护，目录结构参考 Flutter 官方的联邦插件族。

## 发布

- `vX.Y.Z` 发布 `sm_network/`。
- `proxy-vX.Y.Z` 发布 `sm_network_proxy/`。
